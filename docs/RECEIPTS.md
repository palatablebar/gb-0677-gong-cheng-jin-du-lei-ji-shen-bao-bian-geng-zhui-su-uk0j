# 回单脱敏签证

分包回单含联系人与身份证号等个人信息。月末签证要发给总包与财务，审计又要求争议行能回到原始回单。本子系统在**不改写、不删除原始回单**的前提下，产出可核验的脱敏签证，并按角色控制谁能回查原件。

## 数据流与边界

```
回单CSV(含PII) ──导入──▶ receipts 表(原件, 0600)
                              │ 构建时逐行脱敏（副本，原件不动）
                              ▼
                       脱敏行 + HMAC令牌 + 行摘要
                              │ 财务发布（单事务）
                              ▼
                 visa_publications(当前生效版本) ──▶ 对外：总包/财务/经办
                       │
        争议行回查（财务/审计，HMAC重算比对）──▶ 审计日志留痕
```

- **只对外展示（脱敏值）**：联系人保留姓、身份证保留前 6 后 4、电话保留前 3 后 4、银行账号仅留后 4。任何对外 JSON、导出 CSV、页面都不出现原值，只附 HMAC 令牌（不可逆）与 SHA256 摘要。
- **仍能回查原始凭据的角色**：`财务`、`审计` 可对单行调用回查接口，系统用服务端密钥对原件重算 HMAC 并与签证令牌比对，全部匹配才回显原值，且每次回查写审计日志。`经办`、`总包` 回查返回 403。
- **原件保护**：原件只写入 `receipts.db`（权限 0600）。同号回单内容不同直接 409 拒绝，不存在“覆盖后原值无法恢复”的路径；脱敏只产出新对象，从不修改源行。

## 角色权限矩阵（X-Role 头）

HTTP 头按 RFC 7230 只能承载 Latin-1，因此 `X-Role` 传 ASCII 键：`clerk`(经办) / `general`(总包) / `finance`(财务) / `auditor`(审计)；响应中的 `role` 与界面显示中文标签。服务端兼容直接传中文标签（仅站内/测试调用）。

| 能力 | 经办 clerk | 总包 general | 财务 finance | 审计 auditor |
|---|---|---|---|---|
| 查看脱敏签证/列表 | ✓ | ✓ | ✓ | ✓ |
| 导出脱敏 CSV | ✓ | ✓ | ✓ | ✓ |
| 公开摘要核验 | ✓ | ✓ | ✓ | ✓ |
| 回查原始凭据 | ✗ | ✗ | ✓ | ✓ |
| 发布签证 | ✗ | ✗ | ✓ | ✗ |
| 查看审计日志 | ✗ | ✗ | ✗ | ✓ |

单机工作台用 `X-Role` 头声明身份（ASCII 键），等同网关已完成认证；接入真实系统时应由认证中间件注入，而非调用方自报。

## 可核验性（三层）

1. **行摘要 `line_digest`**：对脱敏后整行规范化求 SHA256。任何人拿到签证都可重算，改一个字即不匹配（`GET /verify`）。
2. **文档摘要 `document_digest`**：覆盖规则版本、周期、输入摘要与全部脱敏行，整份签证可被整体校验。
3. **HMAC 令牌 `_pii`**：`HMAC-SHA256(字段名+原值, 服务端密钥)` 截断。对外不可反推；持密钥的财务/审计在回查时重算并 `compare_digest` 比对，证明“该脱敏行确实来自这张原始回单”。密钥来自环境变量 `RECEIPT_HMAC_SECRET`，否则在数据目录生成 0600 的 `receipt_hmac.key`，永不写入对外产物。

## 发布失败与重试语义

- **原子发布**：写新版本、切换发布指针、登记台账在一个 `BEGIN IMMEDIATE` 事务内；任一步失败整体回滚，`visa_publications` 旧指针保持有效，对外仍是旧版。失败单独写入 `visa_attempts(result=failed)`，不产生签证版本。
- **重试不新增**：`visa_ledger(visa_no, source_sha256)` 唯一台账记录每张原始回单已纳入哪份签证。同一批回单再次发布直接返回 `action=reused` 与原签证号，不新增版本、不重复纳入。
- **同号不同内容**：导入阶段即 409（`RECEIPT_CONFLICT`），原件不被覆盖。
- 接口提供 `simulate_failure` 用于演练失败回滚，仅作故障注入，不用于正常业务。

## 接口一览（前缀 `/api/receipts`）

| 方法/路径 | 角色 | 说明 |
|---|---|---|
| `POST /ingest` | 全部 | 上传回单 CSV；重复行跳过、坏行隔离、冲突 409 |
| `GET /receipts` | 全部 | 回单列表（不含 PII 原值） |
| `POST /visa/build` | 全部 | 脱敏预览，不落版本 |
| `POST /visa/publish` | 财务 | 原子发布，返回 created/reused |
| `GET /visa/active` | 全部 | 当前生效脱敏签证 |
| `GET /visa/<no>` | 全部 | 指定签证脱敏内容 |
| `GET /visa/<no>/verify` | 全部 | 公开摘要核验 |
| `GET /visa/<no>/reveal/<receipt_no>` | 财务/审计 | 回查原件并留痕 |
| `GET /visa/<no>/export` | 全部 | 脱敏 CSV（含摘要，不含原值/令牌原值） |
| `GET /visa/versions` | 全部 | 版本与发布尝试留痕 |
| `GET /audit-log` | 审计 | 审计日志 |

页面入口：`/receipts`（主导航第 8 项）。样例：`sample_data/receipts/receipts-nov.csv`（6 行）与 `receipts-retry.csv`（3 行重复 + 1 行坏校验码）。所有个人信息均为虚构，身份证校验码按 GB 11643 生成。
